# MongoDB content model

Recommended collections:
- site_settings
- pages
- homepage_sections
- services
- packages
- ready_to_use_products
- media
- projects
- project_categories
- reviews
- social_stats
- articles
- faqs
- how_it_works
- navigation
- footer
- seo
- adsense
- legal_pages
- cookie_settings
- contact_submissions
- newsletter_subscribers
- scheduled_publications
- admins
- password_otps
- analytics_snapshots
- revisions
- backups
- alerts

Each content collection should support status (`draft`, `published`, `scheduled`, `unpublished`), ordering, visibility, created/updated timestamps and revision metadata where applicable.
